# Tank Battle 🎮

一个复古像素画风的网页坦克大战游戏。单文件、零依赖，浏览器直接打开即玩。

## 玩法

- 操控坦克，消灭天上的**敌机**与地上的**敌方坦克**
- 敌机会投掷炸弹，地面敌人会追踪并开火
- 可破坏的砖墙掩体、爆炸粒子、屏幕震动、8-bit 音效
- 难度随分数逐步提升，部分地面精英敌人需要两发才能击毁

## 操控

| 操作 | 按键 |
| --- | --- |
| 移动 | `WASD` 或方向键 |
| 瞄准 | 鼠标 |
| 射击 | 鼠标左键 或 `空格` |

## 运行

直接用浏览器打开 `index.html` 即可，无需任何构建或依赖。

```bash
open index.html   # macOS
```
